# GoldCalculator

محاسبه‌گر شخصی طلا برای موبایل، ساخته‌شده با React + TypeScript + Vite.

## امکانات نسخه فعلی

- محاسبه قیمت بر اساس وزن و قیمت هر گرم
- اجرت درصدی
- سود درصدی
- مالیات درصدی
- نمایش ریال و معادل تومان
- ذخیره خودکار اجرت، سود و مالیات
- انتخاب منبع قیمت دستی یا API
- ذخیره تاریخچه روی دستگاه
- حالت روشن / تیره / خودکار
- فونت Vazirmatn
- PWA قابل نصب روی موبایل

> اتصال واقعی API در فاز بعدی انجام می‌شود. فعلاً بخش API در تنظیمات آماده است.

## اجرا در VS Code

ترمینال را در پوشه پروژه باز کنید:

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده توسط Vite را در مرورگر باز کنید.

## Build

```bash
npm run build
```

### API

در تنظیمات، حالت «دریافت API» را انتخاب کنید، کلید API سرویکس را وارد کنید و «بروزرسانی قیمت» را بزنید.

توجه: در نسخه شخصی فعلی، کلید API داخل مرورگر ذخیره می‌شود. اگر برنامه در آینده عمومی شود، کلید باید به یک backend/serverless proxy منتقل شود.

### نکته نصب روی موبایل

برای نمایش Install Prompt مرورگر، PWA باید از HTTPS یا localhost اجرا شود. اگر برنامه را با IP شبکه محلی و HTTP روی گوشی باز کنید، ممکن است نصب مستقیم فعال نشود.
